Projet réalisé dans le cadre du cours INF232 - Statistiques et Analyse de Données.

Le projet traite le Thème : Plateforme de mise en relation Freelance / Client

L'objectif est de mobiliser l'ensemble des notions étudiées en cours :

    Statistique descriptive ;
    Analyse bivariée ;
    Corrélation et régression ;
    Classification non supervisée ;
    Classification supervisée ;
    Validation croisée ;
    Déploiement d'une application interactive.

Technologies utilisées:

    Python 3.13
    Streamlit
    Pandas
    NumPy
    Scikit-Learn
    Plotly
    OpenPyXL
    statsmodels

Le choix de Python et Streamlit est justifié par leur richesse en bibliothèques scientifiques, leur simplicité de déploiement et leur excellente intégration avec les outils de Machine Learning.

Lancement local

    Installer les dépendances : pip install -r requirements.txt

    Lancer l'application : streamlit run application/Home.py

Déploiement

    Le projet est compatible avec : GitHub;  Streamlit Community Cloud.

Structure du projet

    Génération déterministe des données ;
    Statistique descriptive ;
    Corrélation et régression ;
    Clustering K-Means ;
    Classification supervisée ;
    Prédiction temps réel.
    Conformité au sujet

Toutes les données sont générées de manière déterministe à partir du nom du chef de groupe, conformément aux exigences de l'annexe officielle du TP.
